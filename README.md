# وهبة النجار — نجار في الرياض

موقع مستقل لخدمات الخزائن وغرف الملابس ووحدات التلفزيون والديكورات الجدارية والفواصل وأثاث غرف النوم.

- الاسم: وهبة النجار
- الفئة: نجار
- نطاق الخدمة: مدينة الرياض
- الاتصال وواتساب: +966595080326 / 0595080326
- الإنتاج: https://wahba-carpenter-riyadh.vercel.app/

## التشغيل
Node.js 24، دون اعتمادات تشغيلية.

```sh
npm run build
npm run check
```

مصدر البيانات `src/content.mjs`، والتصميم في `public/assets/styles.css`.
مجلد `dist` ناتج البناء، وينشره Vercel عند تحديث فرع main.

## دقة البيانات
البيانات الأساسية قدمها المستخدم. لم يقدم عنوان شارع أو رابط ملف تجاري أو ساعات عمل أو تقييمات أو صور أعمال سابقة. الخريطة لمدينة الرياض كنطاق خدمة، والصور تصورات تصميم أصلية مع توضيح ذلك للزائر. تفاصيل الخامات والأسعار والمواعيد تُناقش عند الطلب.
السكيما تشمل Organization وWebSite وWebPage وService وOfferCatalog وBreadcrumbList وArticle وImageGallery. لا توجد تقييمات أو عنوان محل مخترع في البيانات المنظمة.

## Search Console
يمكن ضبط قيمة GOOGLE_SITE_VERIFICATION أو حفظ رمز HTML الصحيح في brand.verification، ويُضاف داخل head في الصفحات المبنية. لا توجد قيم إثبات تجريبية. يظل الرمز في النسخة المنشورة بعد إثبات الملكية.

## الطلب والقياس
النموذج يجهز نص WhatsApp محليًا، ولا يرسل رسالة تلقائيًا أو يخزن بيانات. إشارات dataLayer: phone_click وwhatsapp_click وquote_request وmap_click.
