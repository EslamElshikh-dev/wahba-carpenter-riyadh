- معرّف Google Business Profile: 1310426400263731431
- الإنتاج: https://wahba-carpenter-riyadh.vercel.app/

## التشغيل
Node.js 24، دون اعتمادات تشغيلية.

```sh
npm run build
npm run check
```

مصدر البيانات `src/content.mjs`، والتصميم في `public/assets/styles.css`.
مجلد `dist` ناتج البناء، وينشره Vercel عند تحديث فرع main.

## دقة البيانات
البيانات الأساسية قدمها المستخدم. في 12 أكتوبر 2026 طُوبق الاسم والفئة والرقم والموقع ونطاق الخدمة مع ملف Google التجاري، وقُرئت ساعات العمل ومعرّف الملف من الإعدادات الفعلية. لا يتوفر مقر يستقبل العملاء في بيانات الملف؛ الخريطة لمدينة الرياض كنطاق خدمة، والصور تصورات تصميم أصلية مع توضيح ذلك للزائر. تفاصيل الخامات والأسعار والمواعيد تُناقش عند الطلب.
السكيما تشمل Organization وWebSite وWebPage وService وOfferCatalog وBreadcrumbList وArticle وImageGallery. لا توجد تقييمات أو عنوان محل مخترع في البيانات المنظمة.
المعرّف محفوظ في identifier من نوع PropertyValue. ليس هذا رابط خرائط عامًا أو ضمانًا لتوثيق الملف. يضاف sameAs لملف Google فقط عند توفر رابط عام يمكن التحقق منه. ساعات العمل محفوظة داخل ContactPoint.hoursAvailable.

## Search Console
يمكن ضبط قيمة GOOGLE_SITE_VERIFICATION أو حفظ رمز HTML الصحيح في brand.verification، مع حفظ الرموز الإضافية في brand.additionalVerifications. تضاف جميع الرموز داخل head، ويظل الإثبات الموجود محفوظًا عند إضافة رمز آخر.

## مراجعة 12 أكتوبر 2026
فُحصت الصفحات المنشورة الـ17 وملفات Sitemap وrobots و404 والصور الأساسية. أُجري فحص محلي للأنواع والخصائص ونطاقات الكائنات مقابل مفردات Schema.org الرسمية دون أخطاء؛ هذا لا يعادل نجاح Rich Results Test عند Google. أداة Google أعادت خطأ، والمدقق الخارجي اصطدم بفحص حركة مرور في المتصفح. لم تُقَس Core Web Vitals ولا تُنسب أرقام أداء أو أهلية نتائج غنية دون اختبار فعلي.
طُوّر تباين النصوص على الخلفيات الفاتحة، وأُضيفت ساعات العمل المرئية، وأصبحت أهداف اللمس في الهيدر الصغير 44×44 بكسل. آخر تعديل للموقع محفوظ في brand.updatedAt ويستخدمه Sitemap.

## الطلب والقياس
النموذج يجهز نص WhatsApp محليًا، ولا يرسل رسالة تلقائيًا أو يخزن بيانات. إشارات dataLayer: phone_click وwhatsapp_click وquote_request وmap_click.
